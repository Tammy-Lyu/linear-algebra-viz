# 线性代数交互可视化

同济《工程数学·线性代数》第七版教学配套交互可视化页面（超星教学智能体 TF2 嵌入用）。

## 页面清单

| 模块 | 知识点 | 路径 |
|---|---|---|
| 矩阵 | 矩阵的秩 | [矩阵的秩/](矩阵的秩/) |
| 向量组 | 向量组的线性相关性 | [向量组线性相关性/](向量组线性相关性/) |
| 行列式 | 三阶行列式的几何意义 | [行列式_几何意义/](行列式_几何意义/) |
| 线性方程组 | 解的几何意义（三平面交）| [线性方程组_解的几何/](线性方程组_解的几何/) |
| 相似对角化 | 特征值与特征向量 | [相似对角化_特征向量/](相似对角化_特征向量/) |
| 二次型 | 标准形与曲面 | [二次型_曲面/](二次型_曲面/) |

## 技术
- Three.js r128（本地自包含，无外部依赖）
- 每个页面：交互滑块/输入 + 实时数学计算 + OrbitControls 3D 拖拽
